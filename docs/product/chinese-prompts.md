# 中文提示词模板

这份文档不是给模型 API 直接用的“系统 prompt”，而是给你在当前应用里填写资料、尤其是 `Extra context` 时直接复制用的模板。

## 模板 1：城镇支线基础版

把下面内容直接复制到 `Extra context`，然后按你的团况改：

```txt
请为我生成一个可以插入当前长团的城镇支线模组草案。

要求：
- 地点：瓦拉奇
- 队伍等级：5级
- 风格：调查 + 悬疑
- 时长：3小时左右
- 与主线关系：弱回接，但结尾要能引回圣骨失窃相关主线
- 不要破坏现有主线人物关系
- 优先使用当前城镇里已经出现过的地点或NPC
- 奖励以情报、关系推进、后续线索为主，不要给太强装备

希望输出偏向：
- GM可直接开团
- 场景清晰
- 每个场景都有明确目标
- 最后有一个可回接主线的收束点
```

## 模板 2：你已经改了很多主线时

适合“官方模组已经被你改得比较多”的情况：

```txt
请基于当前 campaign memory 和已 review 的 canon，生成一个可插入现有长团的支线草案。

额外要求：
- 优先遵守 GM 改动记录，不要优先回到官方原文
- 不要让已经改变状态的 NPC 回到原始官方设定
- 不要写出和最近两次 session 冲突的内容
- 支线结束后，玩家应当能自然回到当前主线压力点

这次我更想要：
- 一个城镇内部的调查型事件
- 以民间传闻、失踪、夜间活动、隐藏地点为推动力
- 战斗不是主轴，但高潮可以有一次中等强度冲突
```

## 模板 3：想做 one-shot 风格的支线

```txt
请生成一个可在 1 次到 2 次团内跑完的城镇支线草案。

要求：
- 总时长控制在 2.5 到 4 小时
- 节奏紧凑
- 开场 hook 要直接
- 场景数量控制在 3 到 4 个
- 结尾给出一个明确结果
- 仍然保留一个可以接回长团主线的线索

不希望出现：
- 大量新世界观设定
- 脱离当前 campaign tone 的搞笑桥段
- 完全独立、跑完就无后续价值的结尾
```

## 模板 4：Monster Hunt 版

```txt
请生成一个城镇驱动的 monster hunt 支线草案。

要求：
- 怪物威胁必须与当前城镇环境相关
- 不要只是“杀怪任务”，要有调查或追踪过程
- 需要至少一个可互动 NPC
- 最终战前最好有一个线索反转
- 奖励优先给情报、声望或后续线索，不要给破坏平衡的装备

希望最后能带来的效果：
- 玩家觉得自己解决了一个真实的城镇问题
- 同时得到一点指向主线的新信息
```

## 模板 5：你只想让它更稳，不想让它乱发挥

```txt
请保守生成，不要过度扩写。

要求：
- 尽量复用现有 canon 中已经出现的人物、地点、 tension
- 不新增太多世界设定
- 不要制造与当前主线竞争的巨大支线
- 支线规模保持在“长团中的一个插入型 side quest”
- 输出以可执行性优先，不以华丽文本优先
```

## 最推荐的组合方式

第一次用时，建议这样组合：

1. `Town vibe`：写氛围
2. `Local tension`：写当前压力
3. `Extra context`：贴上面任意一个模板，再按桌况改

## 使用原则

> [!tip] 原则 1
> 不要只写“帮我生成一个支线”。
> 你越明确“要怎么接主线、不要碰什么、偏什么类型”，结果越稳定。

> [!tip] 原则 2
> 如果你的 campaign 已经被你改过很多，就在模板里明确写“优先遵守 GM 改动记录”。

> [!tip] 原则 3
> 如果你只是想拿一个能开团的草案，就要求“保守生成，不要过度扩写”。
