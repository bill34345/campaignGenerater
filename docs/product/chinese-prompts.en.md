# Chinese Prompt Templates

This document is for copying into the app, especially into `Extra context`.

## Template 1: Basic town-side-quest draft

Paste this into `Extra context` and adjust it for your table:

```txt
Please generate a town-based side-quest draft that can be inserted into my ongoing campaign.

Requirements:
- Location: Blackwater
- Party level: 5
- Tone: investigation + mystery
- Length: about 3 hours
- Main plot relation: weak return path, but the ending should feed back into the relic-theft storyline
- Do not break existing relationships between main plot NPCs
- Prefer locations or NPCs that already exist in the current town
- Rewards should focus on information, relationship progression, or future hooks, not strong gear

I want the output to lean toward:
- GM-ready playability
- Clear scenes
- Every scene should have a concrete goal
- A clear closing beat that can return to the main plot
```

## Template 2: When you have already changed a lot of the campaign

Use this when the official module has already been heavily modified:

```txt
Please generate a side-quest draft based on the current campaign memory and the reviewed canon.

Additional requirements:
- Prefer the GM override notes over the original module text
- Do not revert NPCs back to their original official state if the table has already changed them
- Do not include content that conflicts with the last two sessions
- After the quest ends, the players should naturally return to the current main plot pressure point

What I want most this time:
- A town investigation event
- Built around rumors, disappearances, nighttime activity, and hidden locations
- Combat should not be the main axis, but the climax can include one moderate fight
```

## Template 3: One-shot style side quest

```txt
Please generate a town-based side quest that can be completed in 1 to 2 sessions.

Requirements:
- Keep total play time around 2.5 to 4 hours
- Keep the pacing tight
- The opening hook should be immediate
- Keep the scene count to 3 or 4
- End with a clear result
- Still leave a clue that can link back into the long campaign

Do not want:
- Large amounts of new worldbuilding
- Comedy that clashes with the current campaign tone
- A fully independent ending that has no future value
```

## Template 4: Monster hunt version

```txt
Please generate a town-driven monster hunt side quest.

Requirements:
- The monster threat must be tied to the current town environment
- It should not be only a kill mission; include investigation or tracking
- Include at least one interactive NPC
- Before the final fight, there should be a clue reversal
- Rewards should prefer information, reputation, or future hooks rather than balance-breaking loot

Desired outcome:
- The players feel like they solved a real town problem
- They also gain a new lead for the main plot
```

## Template 5: Keep it conservative

```txt
Please keep the generation conservative and do not overexpand.

Requirements:
- Reuse existing canon facts, locations, tensions, and NPCs whenever possible
- Do not add too many new setting elements
- Do not create a giant side thread that competes with the main plot
- Keep the result at the scale of an insertable long-campaign side quest
- Optimize for playability, not for literary prose
```

## Recommended combo

For a first run, use this combination:

1. Fill in `Town vibe`
2. Fill in `Local tension`
3. Paste one of the templates above into `Extra context`

## Basic rule

> The more explicit you are about tone, return path, and what should not happen, the more stable the draft will be.
